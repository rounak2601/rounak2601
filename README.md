## About Me

I am **Rounak Kumar Tilante**, a Computer Science graduate (B.Tech, 2025) based in Hyderabad, India, working across AI/ML, data science, and backend engineering.

My experience spans the full data-to-model pipeline: cleaning and structuring raw datasets, engineering features, building and tuning machine learning models, and exposing predictions through production-style REST APIs. I built a real-time fraud detection system using FastAPI, Kafka, PostgreSQL, Neo4j, and an ensemble model (XGBoost, Graph Neural Networks, Isolation Forest) with SHAP-based explainability — end to end, from data pipeline to API to a working front end.

Alongside model building, I work with large language models and prompt engineering: designing, testing, and evaluating prompts for GPT-based systems and applying GenAI concepts to practical workflows.

I also translate technical work into business-facing insight — Power BI dashboards, statistical analysis, and clear explanations of model design decisions and trade-offs for non-technical stakeholders.

I am currently expanding my knowledge of deep learning, data pipeline architecture, and graph-based machine learning, and I am open to full-time opportunities in Data Science, AI/ML Engineering, Data Engineering, or Prompt Engineering.
